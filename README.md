## 📖 About This Tool

This application manages the list of papers for the ICRA 2026 conference. It provides a simple way to view, sort, and filter research papers without manual spreadsheet work. You can mark papers to read, save your favorites, and track which sessions you want to attend. The interface remains clean and removes the stress of browsing long lists of data.

This tool runs on any modern version of Microsoft Windows. You need a stable internet connection for the initial setup. Ensure your computer meets these basic specifications to guarantee smooth operation:

- Operating System: Windows 10 or Windows 11
- Processor: 1.5 GHz or faster
- Memory: 4 GB of RAM
- Storage: 200 MB of free space
- Display: 1280x720 resolution or higher

Find the icon named ICRA Paper List on your desktop. Double-click the icon to launch the main window. If a security prompt appears, click Run to verify the application. The software loads the list of papers once it connects to the server for the first time.

## 🔍 Using the Features

The main dashboard displays all available papers sorted by their presentation date. Use the top menu to toggle between different views.

### Searching for Papers
Type keywords such as "robotics," "vision," or "learning" into the search bar. The tool updates the list instantly. You can clear the search at any time by clicking the X button in the search field.

### Managing Favorites
Click the star icon next to a title to add that paper to your favorites list. Access your chosen items by clicking the Starred tab at the top of the window. This feature helps you prepare your conference schedule.

### Exporting Data
You can save your current selection to a file on your computer. Click File in the top menu and select Export. Choose a location to save your list. This file uses a standard format that works with most document and spreadsheet programs.

## ⚙️ Updating the Application

The software checks for updates whenever you launch it. If a new version exists, a notification appears on the screen. Click Yes to perform the update. This keeps your paper list current throughout the conference cycle. Your settings and favorited papers transfer to the new version automatically.

## 🛠 Troubleshooting

If the application fails to open, check the following items.

- Verify your internet connection. The app requires access to the network to pull the latest paper list.
- Check for Windows updates. An outdated operating system can block certain program features.
- Restart your computer. This clears temporary issues that stop software from loading.
- Reinstall the application if you encounter recurring errors. Remove the old copy via your Control Panel, then download a fresh copy using the link provided in the setup section.

## 📁 Data Storage

The application saves your preferences, like your list of favorites, in a local folder on your drive. You do not need to log in or create an account. Reset your data by going to Settings and clicking Clear Local Data. Use this option only if you want to remove all stars and saved information.

## 💡 Best Practices for Researchers

Use the filter tools to isolate specific topics. For example, toggle the category filters to show only papers related to navigation or perception. Limit your view to specific sessions to avoid information overload. Create a plan for each day of the conference by using the Favorites tab as your primary guide. 

This tool serves as a personal assistant for your research workflow. It removes the need to track paper IDs or conference URLs on separate notes. Keep the software open during your review sessions to maintain immediate access to the full list of titles and authors.
